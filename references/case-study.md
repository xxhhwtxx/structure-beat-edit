# 参考案例与验证边界

这是方法来源，不是固定模板，不携带原用户媒体、绝对路径或项目专属资产标识。

## 已执行验证：校园静帧卡点片

一个 1080P、30 fps、386 帧的校园项目使用六张照片和 41 个局部上色事件。流程实际包含原图分辨率核验、替换较低清晰度素材、遮罩重画、保留音轨、FFmpeg 导出、全部帧解码与接触表检查、原尺寸边缘定位和重新导出。

实际发现并修复的问题：

- 校名上色矩形带入左侧三角装饰。
- 校门整矩形填进门洞；天空用水平边界切进门洞内部。
- 水面显色带到花枝和花心；颜色阈值漏掉浅色花瓣。
- 等宽座椅切片切到真实色块中部。
- 图书馆天空带到背景楼墙面；工科楼地面条带带到低窗。
- 航拍门体遮罩框进地面与车辆，绿化误选广场标线。

压缩平均误差小并不能发现以上语义错误；只有看原尺寸的实际合成才能定位。该案例验证了静帧遮罩与复核方式，不证明所有相机运动跟踪可靠。

## 已观察分析：14 秒结构卡点参考

| 大致范围 | 观察到的语法 |
|---|---|
| 0–2.4 秒 | 黑白茶园中人物先显色，茶垄依实体形状逐段累计变绿，随后回到黑白 |
| 2.4–4.1 秒 | 窗墙上少量窗格显色，数量逐步增加 |
| 4.1–6.4 秒 | 墙体收起，黑底窗格阵列扩充、合拢、倾斜和放大，再回到窗墙 |
| 6.4–7.5 秒 | 横向亮带扫描，短暂叠入手碰开关的实拍插片 |
| 7.5–10.1 秒 | 黑底台阶逐级出现，转到楼体中间体块，依阶梯结构逐块拼回并恢复背景 |
| 10.5–12.6 秒 | 明暗变化、暖金橙色与冷色反相短长交替 |
| 12.6–14 秒 | 下一建筑擦除/推移进入，最后橙色光带沿框架扫描并留下红色灯线 |

这些是抽帧观察与音频瞬态辅助分析，不是完整复刻后的执行认证；没有把原音频直接播放给分析模型。新项目需验证实际音乐落拍、抠图、变换与衔接，不能因为技能写有某手法就声称已经具备现成资产或原生模板。

本 skill 的两个脚本只负责媒体证据与静帧遮罩辅助；时间线编辑仍由当前项目工具实现。

工具实测范围见 [验证记录](validation.md)。
