# 遮罩与边界

## 层级与语义

从当前工作图建立：目标实体、实体孔洞、前景遮挡、相邻排除对象、背景。大矩形加颜色阈值不能替你理解物体。

- 校名：左右留适度边距，排除装饰。指出多出一角时先检查该状态，不顺带改整镜风格。
- 校门：外轮廓减门洞；核对内侧柱、顶梁厚度和透视；排除地面、车辆。
- 花瓣：保护浅色花瓣、花心和细枝。只选粉色会漏白瓣与黄色花心，导致水面上色穿孔。
- 水面：倒影属于水面；真正的前景花枝和栈道要排除。
- 天空：沿屋顶、树梢、远景楼收边；固定水平边界容易横切物体或门洞天空。
- 地面：沿楼基透视，避免固定横条染到低处窗户。
- 绿化：空间范围、保护层和连通性共同排除标线、招牌与车辆。

## 工具选择

| 方法 | 适用 | 边界 |
|---|---|---|
| 多边形/路径 | 固定建筑、屋顶、门洞 | 裁切与透视需对应 |
| HSV/Lab | 蓝天、粉花、绿植候选 | 同色不同物，不能独立证明语义 |
| 连通域 | 清零散误选、找大面积天空 | 真实细花瓣与远处小树也可能很小 |
| 闭运算/填孔 | 修小缝、保护花心 | 可能抹掉门洞、窗缝和天空缝隙 |
| GrabCut/细化 | 可靠粗轮廓的窄边缘 | 固定随机种子；玻璃与天空容易混淆 |
| 跟踪/逐帧蒙版 | 相机移动、遮挡变化 | 静帧工具不等于视频跟踪 |

1080P 羽化可从约 0.4–1.2 px 试起，依对焦与运动模糊调整，不是固定验收参数。宽羽化染亮邻物，过度收缩留下灰边。

## 审看

在原景、暗黑白底及实际需要的黑底上检查。描边图只帮助找错位，最终看无描边合成。先全图，再原尺寸检查屋檐、孔洞角、窗缝、花瓣边、树梢和地面连接线。

相邻区域的交界要有明确所有权。累计显色用正确的 alpha 联合，替换闪现不留上一状态；两者都要保留前景保护层。

`mask_tools.py` 读取归一化多边形、孔洞、HSV 条件与已定义层的引用，输出 alpha、边界图、单层合成、累计/替换预览及面积记录。它提供静态图的机械辅助，不自动理解物体，不做跟踪；阈值需针对实际图像验证。
