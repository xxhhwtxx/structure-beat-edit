# 结构效果编排

## 显色的三种状态规则

设第 i 个对象的 alpha 为 `a_i`，取值 0–1。

- 累计显色：`A_i = max(A_(i-1), a_i)`，或使用正确的 alpha 联合；避免重复相加使边缘变亮。
- 替换闪现：`A_i = a_i`。前一区域回到黑白，适合有意的对答节奏。
- 完整揭示：`A = 1`。独立的到达点，并非每镜必须出现。

参考中的茶垄与楼体拼合有累计关系；早期校园成片的局部闪现使用替换关系。两者不能因为脚本方便就互换。

## 以物体为单位

| 结构 | 可选动作 | 容易失败的替代做法 |
|---|---|---|
| 茶垄、座椅色块 | 沿真实排列逐块点亮 | 等宽矩形穿过结构中部 |
| 窗格 | 抽离、阵列扩充、上下合拢、整体倾斜 | 带入墙面、窗缝消失、透视不一致 |
| 台阶 | 沿透视逐级建立，连接阶梯形楼体 | 所有台阶等高，顺序与空间不符 |
| 柱与楼体 | 抽出主体后分组拼合，再恢复背景 | 门洞填满、前景树跟着楼移动 |
| 灯线与框架 | 受轮廓约束的扫描，经过后留下颜色 | 光带脱离结构、颜色状态不一致 |

## 黑底抽离

先建立可靠的对象 alpha，再隐藏原背景。窗内应保留的玻璃、反射与窗框需要明确；不把门洞等真正孔洞填实。黑底不是掩盖遮罩穿帮的手段。

移动、旋转、缩放时，图像与 alpha 同步变换。围绕对象自身中心或合理轴点运动；必要时先做透视矫正。缩放需足够源像素，先检查黑底边缘，再检查回到原背景后的对齐。

用预乘 alpha 合成处理半透明边缘，避免插值产生黑边。多对象共享整体变换时建立父级，并保留独立可编辑状态。

## 衔接与最小预览

选一个具体的连续关系：阶梯轮廓、共同中轴、移动方向、亮带方向或屏幕占比。让出镜动作给入镜动作提供起点。变色、反相、插片须有乐句作用，不因参考有就全部堆入新片；不新增无来源的实拍内容。

先验证一个难点对象：原景边界正确；黑底无残留背景/黑边；变换锚点与透视合理；回原景对齐；起点、落拍、结束前一帧和下一状态均有效。之后再扩展，同类物体仍需重新核对坐标。
